## Featured Projects

### [InQuery — Multi-Agent Research System](https://github.com/tameszn/deep-research-multi-agent-system)
A multi-agent research pipeline that searches the web, cross-checks and analyzes findings across sources, and delivers a structured report by email without further input. Agents run in parallel for search, analysis, and writing, with Pydantic used for output validation.

`Python` · `OpenAI Agents SDK` · `Pydantic` · `Gradio` · `Resend API`
&nbsp;&nbsp;[Live Demo ↗](https://deep-research-multi-agent-system.onrender.com/) · [Repository ↗](https://github.com/tameszn/deep-research-multi-agent-system)

---

### [Vendor Invoice Intelligence Portal](https://github.com/tameszn/vendor-invoices-intelligence-portal)
An analytics and machine learning application for procurement teams, combining a freight cost predictor (Random Forest Regressor) with an invoice risk screener (Random Forest Classifier) and an executive KPI dashboard, aimed at reducing manual audit effort on incoming vendor invoices.

`Python` · `Streamlit` · `Scikit-learn` · `Pandas` · `Plotly` · `SQLite`
&nbsp;&nbsp;[Live Demo ↗](https://vendor-invoices-intelligence-system.streamlit.app/) · [Repository ↗](https://github.com/tameszn/vendor-invoices-intelligence-portal)

---

### [Heart Disease Prediction System](https://github.com/tameszn/Heart-disease-prediction-)
A Flask web application that estimates a user's cardiovascular disease risk from key health metrics using a trained Random Forest Classifier, and returns personalized, data-driven lifestyle recommendations alongside the prediction.

`Python` · `Flask` · `Scikit-learn` · `Pandas` · `SQLite`
&nbsp;&nbsp;[Live Demo ↗](https://cardio-risk-predict-mops.onrender.com) · [Repository ↗](https://github.com/tameszn/Heart-disease-prediction-)
